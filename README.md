# Cybersecurity Risk Assessment Framework for Small Businesses

Phase 1 establishes the local Flask application foundation.

## Phase 1 scope

- Flask application factory
- Environment configuration support
- Base HTML template
- Local CSS styling
- Home route
- Health-check endpoint
- Automated smoke tests

Database, authentication, risk calculations, recommendations,
dashboards, and case studies are intentionally outside Phase 1.
